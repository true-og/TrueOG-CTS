# TrueOG-CTS

![Icon](https://git.trueog.net/trueog/website/raw/branch/main/assets/images/logos/Logo-Alternate-Transparent.png)

*ad astra per aspera*

The Combat Test Snapshot (CTS) server stack tracked by TrueOG Network: the Sponge engine behind
cts.trueog.net, its plugin API, the Gradle toolchain for developing plugins against Minecraft's
Combat Test Snapshot 8c, and the Nexus API for Fabric combat tests.

Each component remains an independent Gitea repository and is pinned here as a submodule:

- [Sponge-CTS](https://git.trueog.net/trueog/Sponge-CTS)
- [SpongeAPI-CTS](https://git.trueog.net/trueog/SpongeAPI-CTS)
- [VanillaGradle-CTS](https://git.trueog.net/trueog/VanillaGradle-CTS)
- [nexus](https://git.trueog.net/trueog/nexus)

See each individual submodule for its license and attribution.
